# GDC

GDC is a POS and logistics management system with:

- `backend/`: Express + Prisma API
- `mobile/`: Expo mobile client

## Project Structure

```text
GDC/
  backend/
  mobile/
```

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Mobile

```bash
cd mobile
npm install
npx expo start
```
